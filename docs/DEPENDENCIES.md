# Upstream capabilities and version updates

The initial lock is based on the recursive Git tree inventory of the five exact upstream commits in `registry/dependencies.lock.json`. The registered resources include upstream `SKILL.md` files (including mirrors and maintainer-specific files), Spec Kit command templates/official bug and assessment flows, native configuration families, Ponytail command modes, Archify diagram/PR modes, Agent Skills command wrappers, personas and checklists. Duplicate modes are merged into canonical capabilities, while distinct behaviors are routed explicitly or as complementary resources. Each `skills/trellis-*/workflows.md` names the exact source keys for ordinary tasks and their required/conditional calls. For other tasks `catalog <entry>` exposes all mapped resources, including merged and native ones; this is the explicit fallback, not a substitute for reading the task workflow. This is an inventory-level mapping, not a claim of tested semantic equivalence for every upstream command.

`python3 trellis.py validate` validates structural completeness. `python3 trellis.py coverage` gives every registered source's mapping and primary provider. `python3 trellis.py deps sync` downloads exact commits with Git, does not install hooks or execute scripts, and refuses if registered paths are missing or discoverable `SKILL.md` files differ from the lock. `deps doctor` checks installed sources, commit identity and required native tool availability. `deps resolve <key>` returns the real checked-out path. For native integrations see `providers/`.

## Upgrades

Trellis owns the user entry contract; upstream changes are not silently applied. To upgrade a provider, review the new exact commit and full tree, read all changed skill/command/reference definitions, update the unified capability inventory and task hints, resolve duplicate or conflicting behavior, and add/adjust tests. Fetch into an isolated staging toolkit and run `validate`, `deps sync`, `deps doctor`, local tests and live Codex/Claude task acceptance. Only then release a new Trellis version and reinstall. The current version does not auto-update or auto-approve a newly discovered skill; `deps sync` refuses drift. Native plugin versions must be separately checked when a native host-only feature is used.

Upstream tools may have separate licenses, prerequisites, privacy behavior and services. Only pinned sources are cloned; no upstream code is bundled in this release. Read their licenses and actual instructions before execution. Do not enable global hooks or install unreviewed extensions. Native host-only operations (e.g. Ponytail Band, native Spec Kit extensions, Archify remote PR attachment) are capability-gated, not silently emulated.
