# Spec Kit

pinned source includes raw templates (`templates/commands/*.md`) and official bug/assess extension command templates. Their `{SCRIPT}`, `$ARGUMENTS`, `__SPECKIT_COMMAND_*__`, feature directories and hook substitutions are **not executable shell commands**. For Trellis-managed work, use the method and template semantics with the current user text, R/F IDs and Trellis artifact paths; adapt the method explicitly, do not run unresolved placeholders or duplicate requirements/state. Native commands, hooks, presets, overlays, bundles, catalogs, workflow steps/functions, artifact inventory, integration/admin operations require the pinned Specify CLI and its initialized native project. Inspect `docs/installation.md` and the relevant native command docs, use `specify --help` and actual installed integration output; never claim native execution from reading a template. With explicit user approval install pinned CLI from the checked-out repo (`uv tool install --from <pinned-spec-kit-checkout> specify-cli`, confirm current syntax via `uv` help); create/use a separate authorized native workspace if it would conflict with Trellis docs or expose extra commands. Use official bug/assess extensions only from pinned checkout / approved sources; preserve output and map to R/F and gates. Report missing `uv` or unsupported native command as blocked. Don't silently install community catalogs, execute lifecycle hooks, or move the target project's branch.
