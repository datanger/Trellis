# Changelog

## v0.2.0 — Lightweight preview

- Preserve eight entries and all 136 registered upstream resources; merge routing/coverage into one inventory and keep 58 non-mandatory task hints.
- Remove persistent workflow engine, approval tokens, per-step receipts and file-wide baseline guards. Host plans and executes; major decisions remain explicit.
- Markdown requirements are canonical, with stable IDs, edit dates and strike-through deletion. Add reviewed legacy migration and optional checks.
- Load provider instructions on demand; protect accepted behavior through actual tests, Git and CI.
- Update dual-host install/upgrade and acceptance documentation. Live host parity remains unverified.

## v0.1.0 — Local preview

- Eight stable public skill entries, natural-language task routing using 149 registered workflow templates.
- Five pinned upstream repositories and source-file inventory; duplicate capability families and separate native-host adapters.
- Raw/functional requirement views, stable IDs, approval packets and persistent workflow cursor.
- Progressive design/interface/skeleton/integration/module workflow; explicit human decision gates.
- Actual command test receipts, approved acceptance policy, Git-based protected baseline and change authorization.
- User/project scope installer for Codex and Claude Code; shared versioned private dependency cache.
- Local unittest coverage and CI workflow; Chinese and English installation and use documentation.

Limitations: live upstream download and native end-to-end host verification remain pending; no assertion of complete semantic coverage or secure sandboxing. See `docs/host-acceptance.md`.
