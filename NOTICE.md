# Third-party sources

Trellis is an independent workflow integration. It is not affiliated with the five upstream projects. No upstream code is vendored in this archive; the installer obtains the explicitly pinned checkouts and preserves their license files. The following project names identify the sources of the adapted capabilities:

- Superpowers — https://github.com/obra/superpowers
- Spec Kit — https://github.com/github/spec-kit
- Ponytail — https://github.com/DietrichGebert/ponytail
- Archify — https://github.com/tt-a1i/archify
- Agent Skills — https://github.com/addyosmani/agent-skills

Pinned versions: see `registry/dependencies.lock.json`. Skill instructions are used from their actual checkouts, not copied into this distribution. Check their licenses before redistributing upstream content. Use of trademarks is descriptive.
